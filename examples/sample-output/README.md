# Saved offline example evidence

These files were generated by fresh local CLI execution of the seven checked-in fixtures, then verified with `scripts/check_examples.py`. They contain fictional data and synthetic telemetry (`execution_mode: offline_mock`). They are saved evidence snapshots, not a recorded-replay mode, provider output, invoice, or benchmark. Durations and event elapsed times vary between machines/runs.

The [summary receipt](summary.json) records runtime/platform, UTC retrieval time, fixture byte hashes, exit codes, literal state/usage totals, and per-scenario paths. Each directory contains report.json and events.jsonl. The script checks outcomes, budgets, capacity, ordered events, one terminal per accepted job, no decision after terminal, special fairness/fault cases, and preserved fixture bytes.

Reproduce from the clone root using a separate output directory:

```powershell
py -3.11 scripts/check_examples.py --out work/demo
```

```sh
python3.11 scripts/check_examples.py --out work/demo
```

The command exits nonzero on a failed check. It invokes the public CLI using the same interpreter as the script and replaces files in the selected output directory. Inspect [EVIDENCE.md](../../EVIDENCE.md) for the test/CI boundary.
